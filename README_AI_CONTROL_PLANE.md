# AI Control Plane Overview

This repository now has a proposed structured control plane for multi-AI engineering work.

Start with `AI_START_HERE.md`.

Core files:

- `AGENTS.md` — how ChatGPT/Codex/Cimi/humans work together.
- `PROJECT_STATE.md` — current truth, freshness boundary and state conflicts.
- `DECISIONS.md` — durable architecture/project decisions.
- `TASKS.md` — executable task contracts and handoffs.
- `CHATGPT_PROJECT_INSTRUCTIONS.md` — copy into a dedicated ChatGPT Project.
- `evidence/` — reproducible evidence index.
- `reports/` — conclusion-oriented engineering reports.

The bootstrap deliberately does not rewrite existing historical notes. Its first technical-control follow-up is `STATE-SYNC-001`, which reconciles the six HIGH items still present in `unknows.md` with later repository evidence before future agents treat the ledger as authoritative.
